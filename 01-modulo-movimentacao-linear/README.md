# Módulo de Movimentação Linear

Projeto de um módulo mecânico desenvolvido em CAD para realizar movimentação linear.

## Descrição

Modelagem e montagem de um módulo de movimentação linear desenvolvidas no SolidWorks.

## Recursos utilizados

- Modelagem 3D
- Sketch
- Part Design
- Assembly
- Mates

## Software

- SolidWorks

## Arquivos

- `Assembly/` — arquivos da montagem
- `Parts/` — arquivos das peças
- `Draws/` — desenhos técnicos
