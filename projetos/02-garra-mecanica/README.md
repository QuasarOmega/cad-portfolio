# Garra Mecânica

Projeto de uma garra mecânica modelada e montada no SolidWorks.

## Descrição

O projeto consiste na modelagem dos componentes e montagem de uma garra mecânica, seguindo as dimensões e especificações fornecidas no projeto.

## Software

- SolidWorks

## Arquivos

- `Assembly/` — arquivo da montagem
- `Parts/` — arquivos das peças
- `Reference/`-arquivo de Referencia
